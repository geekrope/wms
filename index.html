The following chart fits the linear regression to the running totals of items added or removed from the inventory over time. The following quantity is computed for each cutoff date: \[t = \frac{\hat{\beta_1} - 0}{\mathrm{SE}(\beta_1)} \sim t_{n - 2}\] which is t-distributed under the null hypothesis \(H_0: \beta_1 = 0\) [1].

However the process exhibits a random walk behavior as \(Y_t = Y_{t-1} + \Delta_t\), where we assume the deltas to be i.i.d. normal with mean \(\mu\) and variance \(\sigma^2\). We test the hypothesis \(H_0: \mu \geq 0\) against \(H_1: \mu < 0\) using the t-statistic. For this we use the decomposition \(\Delta_t = \mu + \varepsilon_t\) and fit 1-d linear regression (degenerate case of linear regression) to determine the parameter \(\mu\). The closed form solution is given by \(\hat{\mu} = \overline{\Delta}\) and the t-statistic in this case has \(n-1\) degrees of freedom \[t = \frac{\overline{\Delta}}{\sqrt{\frac{1}{n - 1}\sum_{t = 1}^{n} (\Delta_t - \overline{\Delta})} / \sqrt{n}} \sim t_{n - 1}\]

The reasoning above invalidates the i.i.d. assumption for the errors in the linear regression model, since the data points are clearly not indepedent as \(\mathrm{Cov} (Y_{t-1}, Y_{t}) = \mathrm{Var}(Y_{t-1}) + \mathrm{Cov}(Y_{t-1}, \Delta_t) = \mathrm{Var}(Y_{t-1}) > 0\) (by independence of deltas). However we keep both test as the first one appears to be more illustrative and takes into account the time spacing.
